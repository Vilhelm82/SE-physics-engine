# RH-1 -- Recovery, dither and re-harmonisation on the split-loop instrument

Spec for Codex. Written 2026-09-06 by Claire (Claude Fable 5.1) from a session with Will.
Status: SPEC. No runs. Designer predictions are banked separately, sealed, and are NOT to be
read before rh1a-d have run. Live build referenced: HEAD `6cd6630`.
Harnesses: `split1_split_loop.py` (ideal-projection trine, `dump_word`), `reflection_loop_finite_dump.py`
(five-loop FD instrument, FD-1 table). Interface: the ideal-projection interface declared in
`docs/2026-09-06-distance-code-test.md` (A = G K_PP, B = K_QP), i.e. chi -> 0 of FD-1 eq. (2).

## 0. The idea, in one paragraph

The endpoint flag is currently consumed as an erasure: a click discards the shot, or (QEC test)
replaces the bright outcome by I/2. Will's proposal, four steps, each one a computed condition below.
(1) The flagged bright amplitude is a STATE, K_QP psi, not a bit. If the flag is data-blind, K_QP is a
scaled isometry and the leaked state is the full data rotated into Q by a known map. (2) A syndrome-
conditioned block at the hold folds it back, so gain leakage is recovered coherently instead of
discarded; the measurement removes any dependence on the gain magnitude. (3) Detuning, which does not
leak, is read STATISTICALLY from the same flag channel by dithering the dump time. (4) The estimate is
absorbed into the frame (virtual re-indexing / LO lock) rather than fought with a counter-block.
Nothing physical is added except a conditional block at the hold. Errors are not suppressed;
they are used as diagnostics. "You don't fight the error, you make it a first-class diagnostic."

## 1. Objects (harness conventions, a = 1)

- Code P = span(d, r) = span(e_2, e_3); bright Q = span(e_0, e_1); target G = diag(-1, 1)|_P.
- Word: loops L_1 ... L_N with a dump after each. Trine: N = 3, angles (pi/3, 2pi/3, pi/3),
  exact_return=True, tau = TAU1. FD: N = 5, FD-1 table, ideal-projection limit chi -> 0.
- Per-loop 2x2 blocks of the 4x4 loop propagator L_k(eps, delta_d, delta_r):
  S_k = P L_k P (surviving plane map, P -> P), E_k = Q L_k P (leak map, P -> Q).
- Discard instrument (current): no-click Kraus op K = S_N ... S_1; a click at any k discards.
  Erasure h = 1 - <psi|K^dag K|psi>; conditional fidelity against G as in `analyse()`.
- Cumulative leak at dump k: F_k = E_k S_{k-1} ... S_1 (P -> Q). Total erasure operator
  R = sum_k F_k^dag F_k = I_P - K^dag K (exact at the ideal interface).

## 2. Definitions

- **DB-k (data-blind at dump k):** E_k^dag E_k = c_k P for a scalar c_k. Equivalently the two
  singular values of the 2x2 block E_k coincide. Metric DB_k = (s1^2 - s2^2)/(s1^2 + s2^2) in [0,1];
  DB_k = 0 is exact. This IS the Knill-Laflamme diagonal condition for the single error E_k on code P,
  and is the precise form of the open item "state dependence of the flag effect" at the ideal interface.
- **Shape:** polar E_k = U_k H_k with H_k = sqrt(E_k^dag E_k) >= 0 on P and U_k an isometry P -> Q.
  Under DB-k, H_k = sqrt(c_k) P and E_k = sqrt(c_k) U_k. U_k is the shape of what leaked.
- **Unitary part of the survivor:** polar S_k = V_k J_k, V_k unitary on P, J_k >= 0.
- **Fold-back block at dump k:** C_k = V_k U_k^dag : Q -> P. It sends the leaked state
  E_k phi = sqrt(c_k) U_k phi to sqrt(c_k) V_k phi, i.e. to what the no-click branch produced,
  up to norm. C_k is a fixed 2x2 map extracted at ONE calibration point eps_0; it carries no
  explicit dependence on the gain magnitude.
- **Recovered instrument:** for click pattern sigma in {0,1}^N,
  K_sigma = prod_{k=N..1} [ (1 - sigma_k) S_k + sigma_k C_k E_k ],  Lambda(rho) = sum_sigma K_sigma rho K_sigma^dag.
  Trace preservation: per loop, S_k^dag S_k + E_k^dag C_k^dag C_k E_k = S_k^dag S_k + E_k^dag E_k
  = P L_k^dag L_k P = P, since C_k^dag C_k is the projector onto U_k(P) which contains the image of E_k.
  Holds with or without DB-k.
- **Average gate infidelity** of Lambda against G, d = 2:
  F_e = (1/d^2) sum_sigma |tr(G^dag K_sigma)|^2,  F_avg = (d F_e + 1)/(d + 1),  report 1 - F_avg.
- **Family split at fixed loop:** E_k(eps, delta) = eps A_k + delta B_k + O(2), with A_k, B_k from
  central finite differences at the nominal point. Distinguishability (KL off-diagonal, needed only
  to tell two families apart at the SAME dump): Omega_k = ||P A_k^dag B_k P|| / (||A_k|| ||B_k||).
  Q is 2-dimensional and A_k(P) may already span it; Omega_k = 0 is NOT expected generically.
  Report it; do not require it.
- **Window dither:** dump k fired at T_k + dt instead of T_k, implemented as the last arc of loop k
  run for duration tau + dt at the same s-rate (s continues past pi/2 for dt > 0, stops short for
  dt < 0), then the dump. Click rate p_k(dt; eps, delta). Asymmetry Asym_k(delta) = p_k(+dt) - p_k(-dt).
- **Re-harmonised comparison:** S_tot = P K P, polar S_tot = V_tot J_tot. Unitary fraction of the
  conditional infidelity = [1 - F(V_tot vs G)] / [1 - F(S_tot normalised vs G)], both on Haar states
  as in `analyse()`. Unitary residual W = V_tot G^dag on P. Z-character:
  Zc = ||[W, D_d - D_r]|| / ||W - P||. Zc = 0 means W is a pure phase rotation in P (virtual-Z
  absorbable); Zc of order one means the residual rotation is tilted off the code axis.
- **Detuning modes:** delta_diff = delta_d - delta_r, delta_com = (delta_d + delta_r)/2.
  NOTE: `split1_split_loop.py` puts `delta` on D3 = D_d ONLY, so it is half common, half differential:
  delta D_d = (delta/2)(D_d + D_r) + (delta/2)(D_d - D_r). The FD harness carries delta_d and
  delta_r separately; use it for the mode split.

## 3. Tests, in order. One at a time. Forks are outcomes, not expectations.

### RH-1a  Data-blindness / KL diagonal
Closes the open "state-dependent flag" item at the ideal interface.
Compute DB_k for every dump k of (i) the trine and (ii) the FD word at chi -> 0, at
(eps, delta_d, delta_r) in {(1e-2,0,0), (1e-3,0,0), (0,1e-4,0), (0,0,1e-4), (0,1e-4,1e-4), (1e-2,1e-4,0)}.
Cross-check: Haar spread/mean of the per-dump click probability (must be monotone in DB_k).
Report the DB_k table and, for gain-only, the per-dump U_k (as the 2x2 block, not a description).
Fork: (a) DB_k < 1e-4 at every k for gain-only -> gain leak is KL-clean per dump.
      (b) DB_k >= 1e-4 at some k -> state-dependent leak survives there; RH-1b still runs and reports
          the distortion it causes.
KILL for the whole fold-back programme: DB_k > 1e-2 at EVERY k for gain-only. Then E_k is not a
scaled isometry and no fixed block recovers it.

### RH-1b  Fold-back recovery (the compressor, measured form)
Extract U_k, V_k, C_k at eps_0 = 1e-2, delta = 0, both words. Build Lambda by click-pattern
enumeration (2^N terms). Evaluate at eps in {5e-3, 1e-2, 2e-2}, delta = 0, with C_k FIXED at eps_0.
Report per eps: (1) discard-instrument h and conditional infidelity (regression against existing
numbers); (2) discard-instrument UNCONDITIONAL infidelity, click branches mapped to I/2 exactly as the
QEC test declares (Lambda_disc(rho) = K rho K^dag + (1 - tr(K rho K^dag)) I/2, Haar-averaged);
(3) recovered-instrument unconditional infidelity, 1 - F_avg(Lambda, G).
Fork: (a) at eps = eps_0, recovered unconditional is within 10x of the discard CONDITIONAL -> the leak
          is recovered coherently and the gate's unheralded error is no longer set by h.
      (b) recovered unconditional is within 10x of the discard UNCONDITIONAL -> fold-back buys nothing;
          report why (DB_k, or C_k mismatch), with the offending dump named.
      Between: report the ratio, no verdict.
Across eps: report recovered unconditional at 5e-3 and 2e-2 relative to eps_0 and the fitted exponent
of the excess in (eps - eps_0). Do not assume 2; fit it.
Variant, same run: "replay" recovery C_k' = S_k U_k^dag (fold back, then re-run loop k, with a second
chance to leak). Report whether it differs from C_k at the reported precision.
HELD OUT: the absorbing chi > 0 interface. There the leaked amplitude is destroyed; the fold-back needs
a held coherent-capture mode in place of absorption. That is a MODEL EXTENSION, not part of RH-1b.

### RH-1c  Window dither as a detuning meter
Trine, eps = 1e-2 fixed (and repeated at eps = 0). delta_d in {-1e-3, -3e-4, -1e-4, 0, 1e-4, 3e-4, 1e-3},
delta_r = 0, dt in {+-0.02 tau, +-0.05 tau}; dither the LAST dump only, others at nominal time.
Report: (1) p_N(0; delta) vs delta with fitted exponent over all seven points (two points is a line,
not a law); (2) Asym_N(delta) at each dt; (3) dt*(delta), the location of the minimum of p_N over dt by
local quadratic fit; (4) leading-order bright amplitude vectors alpha = d(Q L_N psi)/d(delta),
beta = d(Q L_N psi)/d(dt) at the nominal point, Haar-averaged, and their alignment |<alpha,beta>|/(|alpha||beta|).
Fork: (a) Asym_N linear through zero in delta, nonzero slope, dt*(delta) linear in delta, alignment near 1:
          the return WINDOW moves with detuning; the dither is a sign-resolving phase detector.
      (b) Asym_N = 0 within numerics, dt* does not move: detuning lifts the minimum without shifting it;
          the dither is blind; a tuning dither (known delta_0 added) is the only estimator and it costs
          real in-plane error.
      (c) partial: report alignment and the fraction of p_N(0; delta) removable by the best dt.
Under (a): Fisher information of the Bernoulli rate w.r.t. delta at the operating dt; shot count for
delta resolution 1e-5 at eps = 1e-2; and DB of the dithered E_N at delta = 0 (is the dither's own
added erasure data-blind?).
KILL for the diagnostic reading: fork (b) AND the tuning-dither estimator costing more conditional
infidelity than the detuning it estimates would have caused.

### RH-1d  Re-harmonisation (virtual) and lock (physical)
(i) Virtual, both words. Points (eps, delta_d, delta_r) = (0,1e-4,0) [both], and FD only:
(0,0,1e-4), (0,1e-4,1e-4) [pure common], (0,1e-4,-1e-4) [pure differential].
Compute S_tot, its polar parts, the unitary fraction of the conditional infidelity, and Zc of W.
Report the fraction of the existing conditional infidelity (2.4e-8 at the trine point) that is unitary.
Fork: (a) unitary fraction > 0.99 and Zc < 1e-2 -> the residual is a phase rotation in P, absorbable
          by re-indexing the readout basis (virtual Z), zero physical cost.
      (b) unitary but Zc of order one -> absorbable by a rotated readout, still zero pulses, but the
          NEXT word's angles must be re-solved for the rotated target.
      (c) non-unitary fraction comparable to the total -> no frame absorbs it; it is a channel error
          and stays on the moment-condition tier.
Record delta_com and delta_diff separately. The hypothesis to TEST, not assume: delta_com behaves as a
gap change (fork c), delta_diff as a phase (fork a).
(ii) Physical lock, trine, differential mode. Implement the frame rotating at rate delta_hat on
(D_d - D_r)/2 by replacing the real coupling vectors p, q in `loop_prop` by their frame images
exp(+i delta_hat t (D_d - D_r)/2) p, q. These are COMPLEX: this leaves the real-symmetric family of RF-7
and must be recorded as a MODEL EXTENSION in the report. At delta_hat = delta: check the propagator equals
nominal (a gauge identity -- verifies the implementation, not the physics), erasure returns to the
eps-only value, and RH-1c's dt* returns to 0. At delta_hat = delta(1 +- 0.1): residual conditional
infidelity and the fitted exponent in (delta - delta_hat).
(iii) Common-mode control: repeat (ii) with delta_d = delta_r = delta and the lock on (D_d + D_r)/2
(a re-phasing of the P-Q coupling, i.e. a retuned drive). If the window and erasure do NOT return under
this lock, common-mode code detuning is a gap error and re-harmonisation does not reach it. Report either way.

## 4. What is proved already, what is not, and lineage

PROVED (one line each; no run needed):
- DB-k <=> E_k^dag E_k proportional to P <=> the KL diagonal condition for the single error E_k on P.
- Under DB-k, C_k = V_k U_k^dag returns the leaked branch to the no-click branch's image exactly.
- E_k^dag E_k proportional to P is invariant under ANY unitary change of frame on P. Re-harmonisation
  cannot break data-blindness once it holds. (The tight-frame derivation was the route; the
  conclusion is frame-covariant. In the wrapper: the augmented triad is its own inversions.)
- Lambda in sec. 2 is trace preserving with or without DB-k.
DERIVED, conditional on the run: every fork in section 3.
NOT CLAIMED: anything at the absorbing chi > 0 interface; any hardware feasibility; family
distinguishability at one dump (Omega_k is reported, not required); anything about stochastic
(shot-to-shot) gain or detuning -- the fold-back handles gain of any magnitude because the click
discretises it, but the dither/lock handle only DETERMINISTIC or slowly drifting detuning. State that
fence in the report.
LINEAGE, instrumental only: KL conditions and unitary recovery are the standard code-theoretic frame
(steal the bookkeeping). Leakage-reduction units reset leakage incoherently; the fold-back is the
coherent version, and the LRU literature says what a physical hold must survive. Syndrome-rate drift
tracking exists at code level. The dump-time dither and the gate-level use of the flag as a detuning
meter are not recognised by the author as existing; lineage unsearched. Will does not care about
priority; the lineage is listed because it drags in machinery, not as a reason to hesitate.
