# RH-2 -- Coherent accumulator recovery (the return bus)

Spec written 2026-09-06 by Claire (Claude Fable 5.1) from RH-1's kill, before any runner existed.
Status: SPEC, then RUN by Claire in-session. Predictions sealed in `docs/prereg/RH-2/` before the
runner was written. Base: HEAD `866ff0e`. Builds on `rh1_common.py` WITHOUT modification.

## 0. Why this exists

RH-1a proved every per-dump gain leak is rank one: E_k = |l_k><u_alpha|; the spectator never leaks,
so a resolved click at dump k cannot return the data. RH-1a also stated that the stacked sum
F^dag F = sum_k F_k^dag F_k ~ c I is the tight-frame fact, and that "forgetting the dump label after
it has been measured leaves a sum of Kraus branches, not a coherent sum of amplitudes." Those two
statements together say: the recovery exists for the STACKED map and is destroyed by asking which
dump clicked. RH-2 tests the instrument that never asks. Every dump is a coherent send into a fresh
held register mode; ONE "any leak?" readout after the last loop; ONE fixed isometry back.
In the wrapper: three aux sends, one return bus, meter the return once.

## 1. Objects (rh1_common conventions; P = indices 2,3; Q = indices 0,1)

- Loops L_k from `word_loops(kind, [case])`. S_k = L_k[2:,2:], E_k = L_k[:2,2:].
  F_k = E_k S_{k-1} ... S_1 (`compose_discard`'s `leaks`). K = S_N ... S_1.
- Stacked leak F = vstack(F_1 .. F_N): P -> C^{2N}. Identity: F^dag F = I - K^dag K, exact.
- DB_stack = (s1^2 - s2^2)/(s1^2 + s2^2) from the two singular values of F. c = tr(F^dag F)/2, the
  erasure. Write delta := DB_stack, the tight-frame deviation.
- Polar F = U H, U a 2N x 2 isometry, H = sqrt(F^dag F) >= 0 on P.
- Accumulator instrument at calibration U_cal: Kraus set
  { K,  G U_cal^dag F,  replacement_kraus((I - U_cal U_cal^dag) F) }.
  The third group is the register amplitude the calibrated isometry does not capture; it stays in
  the register after recovery, is heralded, and is replaced by I/2 (RH-1b's convention). At
  U_cal = U it vanishes identically. The set is trace preserving by construction; report the defect.
- Per-dump comparison line: RH-1b's recovered channel, recomputed with `foldback` on the same loops.

## 2. Tests

### RH-2a  Algebra (no new dynamics)
DB_stack, c, and the identity defect ||F^dag F + K^dag K - I|| for trine and five at gain-only
eps in {5e-3, 1e-2, 2e-2} and at (0,1e-4,0), (1e-2,1e-4,0). Record U (2N x 2) in the receipt.
Fork: (a) trine DB_stack < 1e-4 at gain-only -> the stacked leak is a scaled isometry to that precision.
      (b) not. Five-loop reported the same way; the spec declares no expectation for it.
KILL (whole programme): trine gain-only DB_stack > 1e-2.

### RH-2b  Instrument
Self-calibrated (U at each eps) and fixed-calibration (U at eps_0 = 1e-2) accumulator channels.
Unconditional 1 - F_avg by `channel_metrics`. Report against: no-click conditional, discard
unconditional, and the per-dump recovered line (RH-1b, recomputed).
Derived floor to test against, one line: with Kraus {G J, G H}, J^2 + H^2 = I, J and H commuting
positive with eigenvalue pairs (1 - p_i) and p_i, p_i = c(1 +- delta): the off-diagonal factor is
sqrt((1-p1)(1-p2)) + sqrt(p1 p2) = 1 - c delta^2 / 2 + O(c^2), so
    1 - F_avg (self-calibrated)  ~=  conditional  +  c delta^2 / 6.
Fork: (a) self-calibrated recovered unconditional within 10x of max(conditional, c delta^2/6):
          the accumulator IS the recovery and the tight-frame deviation is its floor.
      (b) within 10x of discard unconditional: dead.
      Between: report the ratio, no verdict.
Fixed-calibration: excess over self-calibrated vs (eps - eps_0); fit the exponent, do not assume 2.

### RH-2c  Detuning pass-through
Same instrument at (1e-2, 1e-4, 0) with U_cal from gain-only eps_0. Report. No claim: the detuning
leak is state-dependent by RH-1a and is expected to pass through the accumulator unrepaired; the
number to report is how much of the 2.4e-8 detuning error the accumulator changes, in either direction.

## 3. Held out (declared model, none of it a hardware claim)
(i) coherent capture of Q into a fresh 2-mode register at each dump, without measurement;
(ii) register modes frozen while held -- H_QQ(T) is nonzero at the endpoint, so a physical Q-resident
amplitude would rotate; the model declares a separate held register instead; (iii) one projective
"register occupied" readout; (iv) the 2N -> 2 isometry U_cal^dag as a physical operation; (v) register
reset. The absorbing chi > 0 FD interface remains a separate model. Stochastic gain magnitude is
handled (the readout discretises it); stochastic detuning is not addressed.

## 4. Kill
Trine gain-only DB_stack > 1e-2, OR self-calibrated recovered unconditional within 10x of discard
unconditional. Either kills the accumulator as a recovery.
