# RH-3 -- the accumulator at the decoder: it makes the gate invisible, and the register may be sloppy

**[numerical | Codex's QEC stack unchanged; 56 runs, 11.2 million trials, single seeds]** At the FD operating point
(n = 1, gain 1%, gamma/a = 1e-6, stack noise p = 1e-3), replacing FD's heralded erasure by an ideal coherent capture
of the same absorbed effect E_h takes the logical failure rate from the erasure gate's level to the perfect-gate
baseline: at d = 3 (X + Z, 400k shots) **FD 445, accumulator r = 0: 313, baseline 327**. The register may replace up
to roughly **r* ~ 0.2-0.3** of its recovered shots by garbage, UNHERALDED, before it is worse than FD's heralding.
At d = 9, 200k shots resolve nothing (0-1 events) except r = 1.

**[provenance]** `experiments/2026-09-06/rh3_qec_accumulator.py` run 2026-09-06 in Codex's venv (`~/.cache/seated-root-qec-venv`: stim 1.16.0,
pymatching 2.4.0, numpy 2.5.2), receipt `rh3_qec-checks.json`, log `rh3_qec.log`. Codes, decoders, stack noise,
shot counts (200k/case) and the seed rule are `rlq/qec_distance_stack.py`; seeds differ from Codex's run only through
run order. FD's channel is `native_channel` on the same operating row and reproduces Codex's per-gate numbers exactly
(herald 0.265055%, unheralded Pauli 4.45092e-6) and its logical counts within statistics on fresh seeds
(d3: 218/227 vs 214/229; d5: 36/35 vs 46/26; d7: 5/4 vs 6/7). Bicycle code not run (BP+OSD; deferred).

## The channel, at the declared interface

    Phi_acc(rho) = A rho A^dag + (1 - r) sqrt(E_h) rho sqrt(E_h) + tr((E_u + B^dag B + r E_h) rho) I/2,  herald = 0

with A = G K_PP, E_h the absorbed (flagged) effect, E_u background, B = K_QP surviving bright -- all from the FD row.
The recovered branch's Kraus operator is G U^dag F = G sqrt(E_h): the isometry cancels, so the ideal self-calibrated
recovery needs only E_h. Exact Pauli twirl w_P = |tr(PA)/2|^2 + (1-r)|tr(P sqrt(E_h))/2|^2 + tr(E_u + B^dag B + r E_h)/8,
verified on the Pauli basis to 6e-16. Per gate:

## Reading, tiered

**[numerical, d = 3 and 5 resolved; d = 7 marginal; d = 9 unresolved]**
- r = 0 is statistically indistinguishable from the perfect-gate baseline at every distance (313 vs 327; 74 vs 47 with
  r = 0.01 at 46 -- Poisson scatter at these counts is +-10-15%). The accumulator removes the gate from the decoder's
  error budget; what remains is the stack noise and a 4.4e-6 background too small to see here.
- FD costs the decoder about 36% more failures than a perfect gate at d = 3 (445 vs 327) and roughly 50% at d = 5
  (71 vs 47): that is the price of 0.265% located erasures per gate at stack noise 1e-3, even with erasure-aware decoding.
- Break-even: r = 0.3 matches FD at d = 3 (456 vs 445) and is slightly worse at d = 5 (89 vs 71); r = 0.1 beats FD at
  both (353 vs 445; 53 vs 71). So **r* is between 0.1 and 0.3**, i.e. the register may fail unheralded on 10-30% of the
  shots it captures and still beat heralding. That is far looser than the "few percent" guessed from threshold ratios,
  because at this stack noise the erasure load is already a large fraction of the budget.
- r = 1 (capture, then lose the state without knowing) is 40-100% worse than FD, as it must be: FD's heralding is the
  correct fallback when the register fails, and any physical register should herald its own failure, which turns
  r = 1 back into FD. The accumulator therefore never has to be worse than FD; r parametrises only the unheralded part.

**[not modelled, and each is a place the accumulator can lose]** register duration and idle cost; capture fidelity at the
absorbing interface (the sink is currently a bath, not a mode); H_QQ rotation of held amplitude; background loss during
the hold; native entangler; hardware. The bicycle code and d = 9 at higher shot counts are unrun. Single seeds.

**[what would change the verdict]** Lower stack noise makes the located-erasure load a larger fraction of the budget and
should widen the accumulator's margin and raise r*; higher stack noise narrows it. Conjecture; a p-sweep is one flag.
